# Group 10 Excel-only analysis workflow

The analysis source for this draft is **`dataset_2.xlsx` only** (a byte-identical copy of `DATASET/dataset.xlsx`). The workbook contains aggregate response-frequency tables, not one record per student. Do not use questionnaire scans, OCR, manual questionnaire transcription, duplicate workbooks, or synthetic rows to build the analysis dataset.

## Workbook audit

Run:

```bash
python data_audit.py
```

The read-only audit uses the repository-local `dataset_2.xlsx` and reports its hash, item-frequency rows, sums of the five response bins, site totals, demographic tally sums, and whether the item totals match their bins. It exits with status `3` when the workbook contains aggregate frequency tables. `others.py` and `others2.py` both use this safe Excel-only audit and stop; neither inventories PDFs nor starts a model.

## What the selected workbook supports

- One sheet with 63 practice-item frequency rows and nine CA frequency rows.
- Frequency counts for response bins 1–5 and aggregate demographic/site counts.
- Arithmetic checks of displayed item totals against the five response bins.

The workbook does not contain linked respondent rows, a respondent-level `TOTAL`, or school IDs attached to responses. Marginal counts cannot be rearranged into student records. The current workbook therefore cannot support OLS/LASSO/ridge fitting, school-grouped validation, coefficients, residuals, or individual-level metrics. The model scripts are not run from the present workbook. No results are generated by this workflow.

`dataset_2.xlsx` is the sole workbook included in this repository and is byte-identical to the selected source `DATASET/dataset.xlsx`. The separate project-root `dataset.xlsx` differs and is excluded from this analysis.
